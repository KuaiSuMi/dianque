# 点雀

日麻线下计分助手。每位玩家用自己的手机登录，同步查看点数、确认支付和保存对局记录。

[项目仓库](https://github.com/KuaiSuMi/dianque)

## 怎么使用

1. **登录并入座**：注册昵称和密码。一人创建牌桌，选择人数、场次和起始点数；其他人扫码或输入房间码加入。
2. **开始对局**：满员后，房主可以随机选座，然后点击“开始对局”。
3. **记录操作**：点击对手的点数卡片发起支付；自摸、立直和流局使用下方按钮，按提示完成确认。金额可用快捷选项，也可自行输入。
4. **检查与更正**：“对战记录”查看每笔操作；记错时使用撤销、重做。房主还可在“牌桌设置 → 修改当前场况”中更正分数和局况。
5. **结束或继续**：房主点击“结束对战”，核对后确认结算。返回大厅可继续下一场，首页“我的对局”可查看个人战绩。

断线后重新打开页面，或换设备登录原账号，即可回到原座位。对局中不能切换房间；结束后可在大厅退出。

## 账号

- 昵称为 1～12 个字，密码为 8～128 位。每位玩家使用自己的账号。
- “我的对局 → 修改密码”需要验证原密码；房间大厅和牌桌设置也有入口。修改后所有设备重新登录，战绩保留。
- 管理员登录后可通过“账号管理”搜索用户、修改昵称或重置密码。原密码不可查看，忘记密码可联系管理员重置。

## 手机上使用

在 HTTPS 页面中，Android 可从浏览器菜单安装应用；iPhone 可在 Safari 中选择“分享 → 添加到主屏幕”。牌桌设置中的“保持屏幕常亮”需浏览器支持。

## 本地运行

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run build
npm start
```

电脑打开 `http://localhost:3000`。手机连接同一 Wi-Fi，打开终端显示的局域网地址，电脑需保持运行。开发时使用 `npm run dev`；前端修改后需重新构建。本地数据保存在 `.wrangler/state`，与线上隔离。

## 部署

在 Cloudflare Workers 中连接自己的 GitHub 仓库，使用以下配置：

| 配置 | 值 |
| --- | --- |
| Worker 名称 | 与 `wrangler.jsonc` 的 `name` 一致 |
| 生产分支 | `main` |
| 根目录 | `/` |
| 构建命令 | `npm run build && npm test` |
| 部署命令 | `npx wrangler deploy` |

后续推送会在构建和测试通过后自动发布。首次部署需完成 Cloudflare 与 GitHub 授权；保留仓库内 Durable Object 绑定及注册配置，避免丢失现有数据。

需要管理员时，在 Worker 的“设置 → 变量和机密”中添加名为 `ADMIN_USER_ID` 的 **Secret**，值为自己部署环境中的目标账号 ID。账号 ID 可在该 Worker 绑定的 Durable Object Data Studio 中查询 `users` 表。不要把真实账号 ID、密码或部署凭证写入仓库；本地调试的值放入已忽略的 `.dev.vars`。

Secret 不随代码推送写入 Git，也不会被普通部署清除，配置方式见 [Cloudflare Secrets 文档](https://developers.cloudflare.com/workers/configuration/secrets/)。

## 检查

```sh
npm run build
npm test
```

测试覆盖账号权限、三/四人记分、支付确认、撤销重做、联机同步和对局记录。手机安装、软键盘、常亮及锁屏恢复仍需真机验证。
