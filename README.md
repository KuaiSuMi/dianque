# 点雀

日麻线下计分助手。每位玩家用自己的手机登录，同步查看点数、确认支付和保存对局记录。

**在线使用点雀：[dianque.me](https://dianque.me)**

[项目仓库](https://github.com/KuaiSuMi/dianque)

## 怎么使用

1. **登录并入座**：注册昵称和密码。一人创建牌桌，选择人数、场次和起始点数；其他人扫码或输入房间码加入。
2. **开始对局**：房间内所有玩家平权，满员后任何人都可以随机选座，然后点击“开始对局”。
3. **记录操作**：点击对手的点数卡片，选择“我方支付”或“对方支付”。自摸、立直和流局使用下方按钮。金额可用快捷选项，也可自行输入；开启简化支付确认时，发起者确认金额后直接结算。
4. **检查与更正**：“对战记录”查看每笔操作；记错时使用撤销、重做。所有人还可在“牌桌设置 → 修改当前场况”中更正分数和局况。
5. **结束或继续**：任何人点击“结束对战”，核对后确认结算，或删除本场全部记录而不计入战绩。返回大厅可继续下一场，首页“我的对局”可查看个人战绩。

断线后重新打开页面，或换设备登录原账号，即可回到原座位。对局中不能切换房间；结束后可在大厅退出。

房间内所有人均可在大厅或对局中的牌桌设置切换简化支付确认和自动掷骰子。新建房间默认开启简化支付确认：自摸、我方支付、对方支付和多家收款都由发起者确认后直接结算；关闭后先由付款方确认，再由所有收款方确认，付款方发起支付视为已确认付款。自动掷骰子默认关闭，从下一局生效，每局开始自动投掷两颗，全桌结果一致，展示两秒 3D 动画并在停止后摆正；系统开启减少动态效果时改为淡入。待确认结算期间不能修改规则。

首页上方显示公告条，点击可查看已发布公告。管理员可留空正文，并为每条公告设置是否自动弹窗；开启后首页、大厅和对局中均可弹出。同一浏览器每条公告只自动弹出一次，刷新、重新打开或编辑公告不会重复；清除浏览器数据后会重新显示。前台页面每 30 秒刷新，返回页面时立即刷新。

管理中心的“概览”展示账号、三/四人已结算场数、在局牌桌与近 5 分钟活跃人数，并可查看今日、近 7 天、近 30 天的访问次数、独立访客、活跃账号、新增账号和 HTTP 请求。访问次数按页面初始化统计，访客按浏览器 Cookie 去重；登录后的访问计入活跃，日期按北京时间。访问与活跃数据从功能上线后记录，已有账号和战绩直接汇总；删除记录后统计同步减少。账号详情展示注册时间、最近访问与已结算场数。

## 账号

- 昵称为 1～12 个字，密码为 8～128 位。每位玩家使用自己的账号。
- “我的对局 → 修改密码”需要验证原密码，房间大厅也有入口。对局中及结算确认前禁止修改密码，管理员也不能重置在局账号的密码。修改后所有设备重新登录，战绩保留。
- 管理员登录后可通过“账号管理”搜索用户、修改昵称或重置密码。原密码不可查看，忘记密码可联系管理员重置。

## 手机上使用

在 HTTPS 页面中，Android 可从浏览器菜单安装应用；iPhone 可在 Safari 中选择“分享 → 添加到主屏幕”。牌桌设置中的“保持屏幕常亮”需浏览器支持。

## 本地运行

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run build
npm start
```

电脑打开 `http://localhost:3000`。开发时使用 `npm run dev`，前端热更新；生产运行前执行构建。本地账号和对局保存在 `data/dianque.sqlite`，退出程序后保留。

需要手机在同一 Wi-Fi 下调试时，将环境变量 `HOST` 设为 `0.0.0.0`，然后访问电脑的局域网 IP 和端口 3000。公网部署保持默认的 `127.0.0.1`，通过反向代理访问。

## 部署

使用 Ubuntu 24.04、Node.js 24 LTS、Caddy 和 systemd。HTTP 接口与 WebSocket 使用同一端口，SQLite 存在代码目录之外；应用以独立用户运行，自动重启，每天备份。

安装、域名 HTTPS、管理员配置、更新与恢复见 [部署说明](deploy/README.md)。当前版本仅部署到普通 Linux 服务器。

后续更新先提交并推送 GitHub `main`，再运行 `npm run deploy`。服务器从 GitHub 拉取对应提交，测试、构建并重启，账号与对局数据保留；不发布本地未提交内容。

## 检查

```sh
npm run build
npm test
```

测试覆盖账号权限、三/四人记分、支付确认、撤销重做、联机同步和对局记录。手机安装、软键盘、常亮及锁屏恢复仍需真机验证。
